# 菜单回顶、Agent 切换与消息回复验收

本文记录 2026-11-02 的验收结果。自 2026-11-03 修订起，备用 Agent 的选择仅在当前任务内生效，每个新任务重新从配置的 API 开始。

## 行为

- 左侧导航成功后重置右侧内容滚动位置，包括重复点击当前菜单；取消未保存提示不回顶。
- Agent 按现有列表顺序切换并回绕，跳过不可用或图片能力不匹配的配置。一次任务首次遍历备用不占额外重试次数，后续重试共用会话预算并遵守各 Agent 的 Retry-After。
- 成功 Agent 按账号和会话保存，重启保留，不改变首选 API。手动更换 API、关闭再开启 AI 重置选择。配置测试只测试指定配置。
- 私聊允许合并回复，首条待回复消息开启固定一秒窗口；请求期间新消息另起一批。空回复不消费触发、不提交记忆，进入切换／重试。
- 群聊继续只在真实 @ 当前账号或达到已设置条数时自动调用；普通群消息、历史、修正和素材补齐不绕过门槛。主动轮次可选择沉默，已完成批次不重做。
- 原发送队列、去重及不确定结果暂停规则保留。所有验收使用合成账号、模拟模型和发送器，没有向真实联系人发送测试消息。

## 验证

- 后端完整回归 307 项通过；随后密钥解密分支的最后调整通过 19 项 Agent 专项和 48 项模型执行、群聊、网络、日志回归。
- 前端单测 36 项通过，模拟 API 浏览器整套 27 项通过，真实隔离后端浏览器整套 18 项通过。
- OpenAPI 类型契约、TypeScript、生产构建、本次修改文件的 Prettier 检查及 Git diff 空白检查通过。构建保留现有的大包体积提示。
- 全库 Prettier 检查仍报告 15 个未修改文件的既有格式问题，本次未格式化无关文件。
- 浏览器首轮群聊重载曾出现模拟接口未覆盖的 `account-scans` 请求；该项单独复跑和完整整套复跑均通过。
- 390px Agent 页面截图已检查，无横向溢出；桌面和窄屏的回顶、重复点击，以及取消导航保留草稿／位置均有浏览器断言。
- 覆盖跨协议与独立密钥、列表回绕、成功后沿用、额外重试预算为 0、Retry-After、空回复、不可用候选、图片能力、请求中新增消息、重启预算、配置冲突、账号删除和跨机器导入。
