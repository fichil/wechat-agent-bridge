# 掉线通知与重新登录恢复

## 问题与修复

2026-11-03 03:14（北京时间）服务器记录账号身份异常，Gmail SMTP 告警连续四次连接失败后停止重试。账号扫描和兼容检查的交叉持锁在隔离测试中复现：扫描持有识别锁等待兼容锁，兼容检查持有兼容锁等待识别锁，导致页面账号和兼容接口超时。

识别锁和兼容锁现在仅交换内存状态，数据库调用、原生进程枚举与发送能力检查均在锁外执行。扫描发布由 SQL 所有者排序；删除使在途扫描失效。原生检查的结果提交校验账号代次、来源状态代次、全局及账号兼容修订和进程绑定指纹，重新登录后旧结果不能解除新身份的暂停。页面查询读取归档与已保存检查状态。

复用 SMTP 通道增加 QQ 预置，清除跨服务器或用户名沿用授权码的可能。投递诊断保存在原有 JSON：阶段、错误码、最近尝试时间、可否安全重试。SQLite 版本仍为 11。临时且确定未提交的告警按 60、300、900、1800 秒退避，之后每 1800 秒重试；已接受或不确定结果不重复投递。修改配置保留当前异常周期，只重排确定未提交的失败；服务重启需完成账号扫描才允许继续告警。
