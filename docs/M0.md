# M0 离线实现说明

## 范围与结构

本阶段只使用合成数据，没有真实客户端连接、网络请求、模型 SDK、自动回复或账号管理。Python 标准库提供 dataclass、Protocol、SQLite、argparse 和 unittest，无需安装依赖。

| 路径 | 职责 |
| --- | --- |
| `wechat_agent_bridge/domain.py` | 账号/会话目标、消息、请求、结果及目标状态 |
| `wechat_agent_bridge/adapters/base.py` | 读取、检查、尝试和核验接口 |
| `wechat_agent_bridge/adapters/mock.py` | 内存合成事件与故障注入 |
| `wechat_agent_bridge/policy.py` | 目标白名单、模式、操作类型和短文本长度上限 |
| `wechat_agent_bridge/state.py` | SQLite 消息去重与动作幂等记录 |
| `wechat_agent_bridge/application.py` | 独立策略校验、暂停、去重、尝试与核验编排 |
| `wechat_agent_bridge/__main__.py` | 固定合成数据演示，脱敏 JSON 输出 |
| `tests/test_bridge.py` | 离线单元测试与 CLI 行为测试 |

Provider、Agent 和聊天 Memory 不参与 M0。消息正文不会改变白名单或模式，也不会触发 shell、文件访问或自动回复。仅可信本地配置可以构造策略与适配器；`simulation_only` 是受信适配器的声明，不是第三方代码的安全沙箱。M0 入口只构造自带 MockAdapter，不支持插件加载或 live 模式。

## 模式与结果

- `read-only`：默认只读，允许读取白名单内合成事件；动作返回 `denied`。
- `dry-run`：检查白名单、操作类型、文本长度、连接、身份、实际目标及已有草稿；通过后返回 `dry_run`，不提交、不占用动作请求 ID。
- `mock`：显式演练内存动作，拒绝声明为非模拟的适配器。不存在真实发送实现。

`attempted` 表示已经进入动作尝试，`ui_confirmed` 表示模拟回读核验匹配，`failed` 表示明确失败，`unknown` 表示无法确认。即使将来实现真实适配器，UI 核验也不能当作收件人送达证明。

调用适配器前先提交 `attempted` 状态，再检查一次目标、草稿与暂停；适配器在动作边界再次检查目标和草稿。动作调用抛出超时或其他未分类异常时保守返回 `unknown`。核验超时、掉线或请求 ID 不匹配也返回 `unknown`。只有适配器能证明未尝试写入的 `AdapterRejected` 才按未尝试的失败处理。

## 去重与数据

消息按账号、会话、消息 ID 联合去重；自己发言和不属于请求会话的事件直接忽略。动作请求 ID 在同一个数据库内全局唯一；同 ID 换内容、操作或目标会被拒绝。记录在调用适配器之前落盘，因此进程在尝试期间退出后，相同请求被视为 `unknown`，不会自动重放。已确认、失败和不明结果均不会用同 ID 重试。

SQLite 只保存标识及动作内容的 SHA-256 摘要、固定结果码和是否尝试过，不记录正文、原始账号、会话或联系人标识。摘要不是加密，低熵输入可能被猜测；状态文件仍应当作本地运行数据保护。CLI 仅输出模式、计数和结果码，异常详情不写入操作结果。

默认数据库在 `.local/` 下并被 Git 忽略。删除或换用数据库会丢失去重历史；不能将这种操作当作 `unknown` 的重试方案。`:memory:` 仅用于合成测试。事件在交给调用方前记为已见，属于基本去重，不是保证消费成功的消息队列；可靠消费确认、保留期限、清理和人工核验解锁留待后续设计。

- Python：3.12.10。

- 测试：36 项 unittest 通过；包含网络 socket 禁用检查、持久化重开、独立 SQLite 连接可见性和 CLI 合成演示。

在仓库根目录：

```powershell
python -X utf8 -m unittest discover -s tests -v
python -X utf8 -m wechat_agent_bridge --state-db :memory:
python -X utf8 -m wechat_agent_bridge --mode dry-run --state-db :memory:
```

本次受限 Windows 沙箱的系统临时目录无法读写 SQLite 文件，初次运行有 5 项临时目录权限错误。将测试临时目录指向工作区后，同一套测试通过；没有跳过持久化测试或放宽应用策略。受限环境可复现为：

```powershell
$testTemp = Join-Path (Get-Location).Path '.local/test-temp'
New-Item -ItemType Directory -Path $testTemp -Force | Out-Null
$env:TEMP = $testTemp
$env:TMP = $testTemp
python -X utf8 -m unittest discover -s tests -v
```

## 已知限制

当前是同步离线原型，mock 超时由故障注入产生，不包含真实 UI 调用的硬截止时间或取消机制。暂停阻止后续动作，无法撤回已经开始的动作。未来适配器必须自行实现有界调用、可靠目标标识和紧急停止；不能仅靠捕获 `TimeoutError` 宣称具备这些能力。

没有速率/费用预算、模型提供方、持久聊天记忆或真实兼容性证据。这些均不在本次 M0 交付内。下一步仅按 [M1 测试计划](M1_TEST_PLAN.md) 准备范围明确的验证，当前不执行其中的真实操作。
