# 离线账号删除、AI 重试与掉线邮件通知验收

## 实现范围

- 离线账号删除：前后端检查状态和修订号，事务清理账号归属数据；扫描提交与删除串行协调，旧账号 ID 的迟到回调不写回。确认框区分本地记录与微信客户端、共享配置、已有备份。多页面清理当前选择，重新登录建立新账号归档。
- AI 重试：默认额外 10 次，0–100 可配置；请求快照、尝试数、等待时间、群聊批次持久化。暂时错误退避等待，不占模型线程；配置/记忆/身份/开关改变中止旧请求。成功记忆与回复只提交一次，发送结果不确定时仍不自动重发。
- 邮件：全局 SMTP/收件人配置、DPAPI 授权码、测试入口和最近投递状态；在线基线之后异常持续 60 秒通知。持久事件去重，临时失败有限补试，投递不确定保留核对；SMTP DATA 前再次检查恢复、删除和配置变化。没有聊天内容进入邮件。
- 身份读取失败先记为 unknown 并复查；恢复发现不只依赖微信 PID 改变。账号状态日志保存进程/版本、识别结果和发布提交，供后续凌晨异常排查。
