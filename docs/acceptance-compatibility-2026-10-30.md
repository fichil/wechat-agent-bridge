# 双版本兼容阶段验证

此记录为阶段结果，尚不代表双版本发送或正式便携 Release 验收完成。

## 构建身份与能力

兼容档案位于 `wechat_compatibility/profiles.json`；Python 读取同一档案，C++ 头由 `scripts/generate_compatibility.py` 生成，构建时检查一致性。4.1.15.56 保留原版与已知补丁两个指纹。4.2.0.9 仅接受 SHA-256 `a81c4770350a4edf3e774413da832a785d7aac50025471b30ea26d1f846b9fb4`，目标文件的腾讯签名已验证有效。

在 Server 2025 x64 上只读验证 4.2.0.9：账号绑定与头像、会话、消息、JPEG、GIF 表情通过；增量基线建立后返回无变化，未出现读取问题。真实图片和表情测试材料由用户主动准备，内容保留在私人环境。未向任何联系人发送测试消息。

该构建的 WCDB 会预分配空白尾页。读取器依据已通过 HMAC 校验的最新页头及 [SQLite 1.3.7 规则](https://www.sqlite.org/fileformat.html#in_header_database_size) 确定有效页数；有效页内的空白或篡改仍失败。完整快照与增量 WAL 缓存使用相同规则。新建空分库没有 Name2Id 时允许建立空基线；有消息表却缺少必要结构仍失败。新增精确 CDN 主机 `snsvideo.c2c.wechat.com`，不放开其他微信域名或私网地址，原图摘要及图像验证保留。

原生发送候选位置通过静态及运行中只读核验：调度函数 121 条、文本构建函数 782 条、分配函数 21 条规范化指令一致（仅屏蔽分支与 RIP 相对地址）。应用/账号虚表、方法槽、账号对象及文件/内存入口签名核验通过。此结果不能替代真实发送、生命周期及非干扰验收；4.2.0.9 发送尚未通过本机验收。

档案中的 `send_text=true` 表示已有对应原生调用实现，可进入显式验收；它不代表机器发送就绪，发送执行器仍强制要求独立的本机验收记录。未经验收的生产发送被拒绝。

## 框架与数据

新增受登录/CSRF 保护的查询和恢复接口；兼容暂停持久存入数据库 v9。合成测试覆盖重启保持暂停、手动任务和设置不能绕过、在途 AI 结果被隔离、未知发送保留、恢复修订号、水位与旧队列不重放、不同构建按账号绑定验收、v8→v9 升级失败回退。

角色/API 配置包采用独立白名单 JSON 格式，只导出角色卡与连接配置，不读取密钥列，不含数据库、聊天、媒体或管理员资料。导入先验证摘要与结构，在暂存数据库应用后替换，已有目标数据备份，替换失败回退。完整历史迁移工具仍接受 v8/v9 包，但此次用户交付仅迁移角色/API。

公网诊断中确认 80/443 可连通，HTTP 返回阿里云备案拦截页；延长测试后 Caddy 成功取得证书。用户确认域名未备案，选择 SSH 私人访问。因此增加独立 `private` 认证模式和固定回环入口，保留公网 HTTPS 模式。私人模式不增加开发环境的额外来源许可，继续验证登录、CSRF、Host、WebSocket 与密码重置后的会话撤销。

## 便携与私人访问阶段结果

0.3.0-dev.1 在 Server 2025 的中文及空格目录通过首次配置、端口冲突、重复启动、管理进程退出后后台存活、登录、Cookie、WebSocket、深链接、密码重置撤销会话、正常停止和只监听回环地址的自动验收。Python 3.12.16 随包运行，测试时服务合计约 205 MiB RSS / 10 个进程。

本机构建的 Win32 启动器已验证启动、关闭窗口后台存活、重新打开显示已有状态及停止。通过 SSH 隧道实际访问远程回环健康接口成功；服务器服务从交互用户会话启动，关闭维护 SSH 后仍运行。发现 Windows OpenSSH 会回收其连接中创建的常驻子进程，部署说明因此明确要求在远程桌面启动 GUI。

后端完整 248 项通过；随后增加的用户暂停迁移保留检查与迁移组 9 项通过。读取单元测试 54 项、前端 35 项及类型/API 契约检查通过。新增档案不完整、未知 ABI、缺失读取回验、映射文件/页头变化和发送验收修订号变化检查。
