# 原生语音回复

角色语音支持“跟随聊天 API”和“阿里云百炼”两种来源。默认跟随聊天 API：在 Agent 的 API 配置中填写语音协议和可选的语音模型，留空时使用聊天模型；此模式使用该配置的基础地址和密钥，聊天自动切换到备用 API 时也随之切换。聊天与语音分别显示测试结果，语音不可用不影响文字聊天。

自然童声可选“阿里云百炼”，展开“百炼语音配置”，填写北京工作空间 ID 和 API Key，保存并测试。独立服务固定使用 `cosyvoice-v3-flash`，所有选择百炼的角色共用这份配置；它不会加入聊天模型或备用 API 列表。密钥仅以当前 Windows 用户的 DPAPI 密文保存在本机，留空更新保留旧密钥，测试失败不覆盖旧配置。

小鲸鱼两版采用 `longhuhu_v3`（龙呼呼女童声）：傲娇群友使用 `你说话的角色是傲娇公主，你说话的情感是neutral。`，孙吧使用 `你正在进行自由对话，你说话的情感是neutral。`。两组真实台词均经微信原生语音试听确认。Finn 继续跟随原聊天 API 的 `cedar` 音色。百炼风格上限为 100 个字符，汉字按 2 个计算；风格须符合[官方音色说明](https://help.aliyun.com/zh/model-studio/cosyvoice-voice-list)支持的指令格式。

独立来源保存在 `data.extensions.wechat_agent_bridge.voice_service`，包含 `service_id`、`voice`、`instructions`，不含密钥。切回跟随 API 会保留原有音色和风格映射。导入、导出、复制、角色演化保留此绑定；配置迁移包不携带独立服务密钥，完整跨机迁移也会清除独立服务配置，需重新填写并测试。数据库仍为 v13，更新/回滚备份保留本机服务配置。

接口 `/api/v1/voice/service/query`、`update`、`preview` 使用现有登录和 CSRF 保护。配置更新和试听要求版本号；正式回复将独立服务版本写入请求快照，配置变更、密钥不可读或合成失败时退回完整原文，不使用其他音色重试。CosyVoice 结果只从北京官方 OSS 域名经 HTTPS 下载，下载请求不携带 API Key；响应大小、合成时限和原生发送保护与现有语音链路一致。

在角色卡的“语音音色”中，按 API 配置填写服务商支持的音色名称，并点击试听。留空使用默认音色：OpenAI 兼容协议为 `alloy`，Gemini 为 `Kore`。试听会请求语音服务，可能产生费用，不会发送微信消息。音色保存在 Character Card V2 的 `data.extensions.wechat_agent_bridge.voices` 中，导入、导出、复制与角色演化保留此设置；AI 不能修改这些用户配置。

跟随 API 模式还可填写“说话风格”（最多 2000 字符），描述声线、语气和节奏，保存在同一扩展的 `voice_instructions` 中。此模式仅 `openai_speech` 协议的 `gpt-4o-mini-tts` 系列支持风格指令；其他模型的界面会明确提示，已有风格不会被静默忽略或改成默认音色。合成失败仍退回原文。风格作为独立的 `instructions` 传入服务，正文保持原样；长回复的各个语音分段使用同一份角色快照设置。

试听文案可填写最多 500 字符的中文或英文，留空使用默认试听句；试听文案只用于当前预览，不保存到角色卡。试听和正式回复共用音色、风格与合成逻辑。接口 `POST /api/v1/voice/preview` 新增可选字符串 `instructions`、`text`，旧请求仍可使用。声音设置的保存、导入导出、复制和角色演化均保留其他未知扩展。

语音和当前微信原生能力验证通过后，AI 自动获得语音能力，无需逐会话开启。AI 可根据角色与上下文选择文字、语音或混合发送。在回复格式中，独立行 `[[VOICE]]` 标记本段为语音，段间继续使用 `[[SPLIT]]`：

```text
这段是文字。
[[SPLIT]]
[[VOICE]]
你好，这是一条人工智能合成的语音。
[[SPLIT]]
这段继续以文字发送。
```

长语音按原文顺序拆分，每条不超过 60 秒。音频经校验后保留 WAV 试听和 SILK 发送快照；AI 任务详情中可查看语音文本、时长并按需播放，不自动播放。合成、编码失败时整段退回原文，先完成全部准备，再一次提交记忆、角色修改与发送队列。

发送遵循现有消息顺序和归档确认。原生调用受理后，还必须匹配当前账号、会话、原生类型 34 和自发消息标识。结果不确定时停止后续队列，不自动重发或改发文字。程序中断可继续已经保存的语音准备结果，不重复请求聊天模型。

原生语音目前仅对已验证的微信 4.2.0.9 精确构建开放。数据库为 v13；发布和回退要求见[两阶段发布](voice-reply-rollout.md)。`scripts/verify_voice_send_live.py` 是显式运行的生产验收工具，强制只向文件传输助手发送三条测试消息，并保留回执、归档、桌面状态及独立的播放验收状态。
