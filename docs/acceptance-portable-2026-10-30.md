# Windows 便携包阶段验收 — 2026-10-30

状态：用户已恢复实施。以下为早期便携包检查记录，新进度见 `acceptance-compatibility-2026-10-30.md`。用户改为新微信号，只迁移角色/API，并选择 SSH 私人访问。尚未发布正式 Release 或执行本轮真实微信发送，不能将阶段结果视为完整生产验收。

## 已完成

- Win32 图形启动器、隐藏的本机管理进程、统一 data 路径、独立子进程兼容、内置 Caddy 与静态网页的构建链。
- 从固定校验值的 CPython 3.12.16 源码生成私有运行时，VC 运行库来自校验过的官方 Python 嵌入式包；Caddy 固定 2.11.7 并检查 SHA-512。发送 DLL 和启动器采用静态 CRT。
- 离线 SQLite 备份、包清单与哈希校验、迁移版本检查、目标数据备份和导入失败回退；撤销旧网页登录会话，暂停自动执行，旧发送队列不重放，未知结果保留。
- 发送验收入口接入后台认证；发送记录可绑定机器、Windows 用户与程序清单，便携包拒绝不带绑定的旧记录。验收必须由用户明确触发。
- 源码工作树后端 229 项测试通过，含 7 项新增迁移/绑定测试；前端 35 项测试、类型检查、构建、API 契约检查通过。
- 真实 Caddy 的回环 HTTPS 验收通过：生产模板、静态/深链接、Secure/HttpOnly Cookie、登录/刷新/退出、WebSocket、手机布局。
- 图形启动器在本机构建后启动成功；初始状态与环境检查按钮通过 UI 验证。未点击发送验收。
- 0.2.0-dev.2 ZIP 约 44 MiB；在没有 Python/Node 开发安装的 Windows Server 2025 x64 上解压，随包 Python 3.12.16、后端全部依赖和原生 DLL 来源哈希检查通过。
