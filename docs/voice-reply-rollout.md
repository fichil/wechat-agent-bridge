# 原生语音回复的两阶段发布

语音功能使用数据库 v13、回复格式 v3。第一阶段仍创建 v12，但可读写 v13，保留语音配置、音频、准备结果及发送证据；新版整轮发送和在途生成任务暂停，普通文字与图片继续使用原数据。

第二阶段前，先更新独立部署控制器，确认上一生产包的 `database_compatible_schemas` 包含 13，且兼容版完整验证通过。功能版才调用 v12→v13 事务迁移。部署器、便携升级和完整迁移均识别 v13。

回退只切换程序，保留当前数据库。升级前备份只用于灾难恢复，不覆盖新增聊天和发送记录。恢复功能版后继续处理尚未发送的语音准备结果；发送结果不确定时仍须核对，不能自动重发。

原生语音适配与验收仅针对已核对的微信精确指纹。真实测试目标为生产账号的文件传输助手；原生受理、归档关联、语音气泡与实际播放分别记录，不能用健康检查替代播放验收。
