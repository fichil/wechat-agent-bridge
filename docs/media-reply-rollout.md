# 媒体回复分阶段发布

生产目标为微信 4.2.0.9 精确构建，媒体功能使用数据库 v11。

第一阶段只发布回退兼容能力，仍新建 v10 数据库。该版本可打开 v11，保留新格式运行、记忆和发送结果；`reply_format_version > 1` 的整轮发送不调度，在途模型任务回退后暂停。旧纯文字任务继续运行。

第二阶段前，独立部署控制器必须更新为允许 v11 的已验证版本，上一生产程序包须声明 `database_compatible_schemas` 包含 11。功能版本才可升级数据库。回退始终保留当前数据，不能使用发布前快照覆盖新消息或发送结果。

真实媒体发送须完成精确构建核验及指定目标验收，不能把原生调用受理或健康检查当作送达证明。
