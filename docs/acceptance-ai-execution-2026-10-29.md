# AI 执行、增量记忆与 API 实测验收

## 交付行为

- 全局 AI 提示词在设置中编辑，所有账号共用；请求包含提示词、角色卡、会话记忆和未处理消息，响应使用 `memory` / `reply` JSON 契约。
- 自动处理对方新消息，支持手动处理和失败重试。已有本地历史分批处理；记忆包含本次生成回复，并注明尚未发送微信。本次没有微信发送实现。
- 消息状态与内容指纹独立保存。补齐转写、修正文字或图片变化后重新处理；未转写语音等待，纯文字 API 的图片等待，视频和附件内容解析暂不支持。
- 后台网络调用与微信同步、SQLite 线程分离，全局最多两个请求，同会话串行。成功结果与记忆、覆盖标记同事务提交；手工修改记忆、关闭 AI、失败及重启不误标完成。
- API 创建、修改先用合成数据测试，失败不覆盖旧配置；图片能力单独探测。测试结果查询中断可继续查询同一任务，不重新发送测试。
- 保留 DPAPI 加密、默认继承、使用中删除保护和草稿／修订号冲突处理。候选密钥不写入任务或日志。

## 边界

一次测试通过不保证后续额度、网络或模型状态永远可用。超时可能发生在服务方已处理请求之后，故失败暂停并要求手动重试；本地成功结果只提交一次，不承诺远端恰好执行一次。

模型记忆的事实准确性仍需用户复核；程序验证结构和并发一致性，保留手工编辑入口。图片转为适配输入的首帧，原始媒体不变；本次不提供完整动图语义、视频或附件理解。
