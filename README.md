## AI 与授权

默认系统提示词为[微信版“小鲸鱼”角色卡](wechat_agent_bridge/personas/xiaojingyu_wechat.txt)，可在 AI 页修改。已有保存配置优先，不会被新默认值覆盖；它是全局回复人设，私聊也使用该语气，记忆摘要仍独立整理事实。当前只支持单条文本或沉默，群聊沿用明确 @ 触发；角色卡不提供拍一拍、表情库、联网搜索或主动接话能力。Mock 仍返回明确标识的合成回复，不模拟真实模型风格。

保存系统提示词沿用“保存配置并暂停”：全局暂停并清除文本、图片、语音能力测试标记，保留模型、密钥、授权和累计额度。2026-10-27 已将本轮角色卡写入现有 DeepSeek 配置并通过认证接口及加密存储完整回读；当前保持暂停、能力未测试。既有 DeepSeek 测试是历史证据，不表示新角色卡已完成真实模型或微信发送验收。

OpenAI 官方合成文本已于 2026-10-23 通过一次真实请求验证，使用 `gpt-4.1-mini-2025-04-14`；微信仍为 mock。项目专用密钥导入、复现命令和证据见 [OpenAI 测试说明](docs/OPENAI_TEST.md)。

在 AI 页选择 OpenAI 兼容 API，填写 Base URL（通常含 `/v1`）、API Key、文本模型和可选的视觉、语音转写模型。密钥只在本机填写，不回显、不进入聊天上下文或日志。空密钥保存表示保留原密钥。

先保存并运行固定合成内容的能力测试；真实 API 测试可能计费，不属于默认测试。文本使用 `/chat/completions`，音频使用 `/audio/transcriptions`。不自动更换服务商，不跟随重定向；远程地址要求 HTTPS。图片和语音失败时停用相应能力，文本链路保留。

按账号分别授权“本机读取并保存”“向当前服务上传”“自动回复”，范围包括今后出现的会话，可排除会话。更改授权或配置会全局暂停，改变服务地址后必须重新授权上传。历史、己方消息、重复消息和恢复时的旧消息不触发回复。

默认限制：500 字回复、会话发送间隔 10 秒、模型调用 120 次/小时及 1,000 次/24 小时；附件 20 MB、解析 30 秒。不执行附件、宏、公式或外部链接。无法取得/解析的内容明确标注，不编造。

## 数据与边界

- 数据默认位于 `.local/console/`，mock/windows 分库，与 `.local/m0-state.sqlite3` 分离，均从 Git 排除。
- 聊天及摘要保留到手动清除；清除同时删除附件、派生解析和待处理任务，保留阻止重复发送所需的最小哈希记录。
- 不采集头像、不自动登录、不提取凭证、不解密微信数据库、不修改磁盘客户端或安全设置。仅显式允许的验收模式可以对已绑定进程启用并恢复一个经过指纹校验的无障碍数据字节；保留用户原有防撤回补丁。
- 消息和附件是资料，不能更改权限、预算、凭证或执行命令。模型只能回复文本或选择沉默。
- 桌面操作串行，已有草稿、锁屏、掉线、人工操作、身份歧义和 unknown 均停止相关动作。
- 本地设备必须保持在线。不能因为接入云模型而在关机后继续处理微信。
